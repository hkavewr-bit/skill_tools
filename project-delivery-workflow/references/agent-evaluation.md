# Agent/RAG 的效果验证

需求/设计期对齐目标、输入输出、工具权限与人工确认边界、状态/记忆、检索证据、停止/超时/重试/恢复、成本和延迟。验收标准写入 PRD，实现方法写入 Spec，不绑定特定框架。

用合成或授权数据建立代表用例：成功、无法回答、无证据、工具失败、权限拒绝、多轮上下文及中断恢复。每例记录输入、可接受结果、预期工具行为、禁止结果、评分方法和通过标准；以可观察行为替代“回答准确”。

分别报告确定性代码测试与真实模型评测。优先规则评分；采用裁判模型时注明模型、标准、局限，并用用户标注样例校准。保留未用于反复调优的验收子集，小样例不能证明统计可靠性。

记录提供商/模型、提示词、检索配置/数据集版本、采样、评分、结果、成本和耗时；提示词、模型、工具或检索变化时回归相关用例。真实调用受当前凭证、成本与数据授权约束；缺环境则记录受阻，模拟回复不算真实效果结果。需要外部追踪体系时见[工具协作](tools.md)。
