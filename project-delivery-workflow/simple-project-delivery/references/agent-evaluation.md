# 轻量 Agent 验证

仅模型或 Agent 决策影响业务结果时读取。

选少量代表性案例验证正常结果及本次变更相关的失败：结构化输出、证据引用、工具选择、权限、工具故障和恢复按风险选取。
每例明确预期结果与禁止动作；权限与敏感数据问题单独判定，不能被平均成功率掩盖。
复用现有固定回归案例，仅变更影响范围内重跑；不要临时更换失败案例来制造通过。
记录影响可复现性的模型、提示词、工具或数据版本，以及运行方式、结果与限制，放在现有证据或进度中即可。
明确真实提供方、模拟、离线或沙箱的差异；真实调用成本及外部副作用遵守现有授权。
无需默认建设评测平台、全量指标或独立报告；有既定验收指标时必须满足，不能用少量冒烟替代。
